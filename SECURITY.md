# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Hydr46605/Lifes/security/advisories/new) for anything that could affect production servers: account data loss, permission bypass, command execution through configuration, ban evasion. Please do not open public issues for vulnerabilities.

Include the Lifes version, Paper build, affected configuration and reproduction steps. You will get an initial response within a few days.
